# 친구 키우기 (돌봐 주기) 설계

작성일: 2026-11-19

## 1. 목적
- 배우면서 모은 ⭐로 친구를 돌봐 주고, 친구가 자라는 모습을 보며 아이가 성취감을 느끼게 한다.
- 지금은 ⭐가 쌓이기만 하고 쓸 곳이 없다. 이 기능이 ⭐를 쓰는 곳이 된다.

## 2. 사용자 결정 사항
- 방식: **직접 돌봐 주기** (보기만 하는 방식이 아님)
- 하나를 다 키우면 **친구 방**으로 보내고, **새 친구를 데려온다**.
- 친구: 🐶 강아지, 🐱 고양이, 🐥 병아리, 🌳 나무
- 그림: Claude가 그린 **부품 단위 SVG** (미리보기 `pet-preview.html`로 승인)
  - 눈 깜빡임, 웃는 눈, 자는 눈, 입 벌리기, 꼬리·날개·잎 움직임

## 3. 목표 / 비목표 / 실패 조건
**목표**
- 배움(찾기 정답) → ⭐ → 돌봐 주기 → 성장, 이 흐름이 아이 혼자서 음성 안내만으로 된다.
- 친구 하나가 다 자라기까지 찾기 약 3판 분량이 걸린다.

**비목표 (이번 버전)**
- 친구 이름 짓기, 꾸미기·옷 입히기, 상점, 시간 경과에 따른 변화

**실패 조건**
- 돌보지 않으면 친구가 배고파하거나 슬퍼하거나 시들거나 작아지는 등, **줄어들거나 나빠지는 표현**이 있으면 실패다.
- 돌보기만으로 ⭐를 얻을 수 있으면 실패다. 그러면 배움을 대신하게 된다.
- ⭐가 없을 때 아이가 막혀서 아무것도 못 하면 실패다.

## 4. 규칙
- **⭐ 잔액** = 지금까지 얻은 ⭐(`progress.stars`) − 돌봐 주기에 쓴 ⭐(`pets.spent`)
- **돌봐 주기 행동**

  | 행동 | 비용 | 성장 |
  |---|---|---|
  | 밥 / 목욕(나무는 햇빛) / 놀기 | ⭐ 1 | +1 |
  | 쓰다듬기, 잠자기 | 무료 | 없음 |

  - 무료 행동이 있어서 ⭐가 0이어도 친구와 놀 수 있다.
- **⭐가 없을 때 유료 행동을 누르면**: ⭐ 표시가 살짝 흔들리고 "별을 모아 오면 줄 수 있어!"라고 말한다. 감점이나 부정적인 표현은 없다.
- **성장 기준**: 단계별 필요한 돌봐 주기 횟수 `[3, 5, 7]` (아기→2단계→3단계→다 자람, 합계 15)
  - 기준을 채우면 그 자리에서 반짝이와 함께 자라고 "와! ○○가 자랐어!"라고 말한다.
- **다 자랐을 때**: 축하 연출 후 "친구 방으로 이사 가요" 버튼(🏡)을 보여 준다.
  - 누르면 친구 방에 들어가고, 새 친구 고르기 화면으로 간다.
  - 다 자란 친구는 이사 전까지 계속 돌봐 줄 수 있지만 더 자라지는 않는다. 이때는 ⭐도 쓰지 않는다.
- **같은 종류 다시 키우기**: 가능하다. 친구 방에 강아지 둘도 괜찮다.

## 5. 화면
- **홈**: 세계 버튼 아래에 **내 친구 버튼**을 둔다.
  - 지금 키우는 친구의 작은 그림이 버튼에 들어간다. 친구가 없으면 🥚? 그림을 보여 준다.
  - ⭐ 배지는 **잔액**을 보여 준다.
- **친구 고르기** (`#/friend/pick`)
  - 처음이거나 이사 직후에 나온다.
  - 4친구의 아기 단계 그림을 크게 보여 주고 "누구랑 친구 할까?"라고 묻는다.
  - 누르면 이름을 말하고 친구 화면으로 간다.
- **친구 화면** (`#/friend`)
  - 윗줄: 🏠, ⭐ 잔액, 🏡(친구 방)
  - 가운데: 친구 그림 (미리보기와 같은 반응 연출)
  - 성장 표시: 다음 단계까지 남은 칸을 동그라미로 보여 준다 (예: ●●○○○). 글자는 없다.
  - 아래: 행동 버튼 5개. 유료 행동 버튼에는 작은 ⭐1 표시를 단다.
  - 처음 들어오면 친구가 인사한다 ("멍멍! 반가워!").
- **친구 방** (`#/friend/room`)
  - 다 자란 친구들이 나란히 서 있다.
  - 누르면 각자 쓰다듬기 반응을 한다.
  - 친구가 없으면 빈 방에 "친구를 다 키우면 여기로 와요"라고 음성 안내한다.
- **배치**: 다른 아이 화면과 같이 스크롤 없이 한 화면에 담는다. 가로가 낮은 화면에서도 같다.

## 6. 저장
- 새 키: `kidsgame.pets.v1`
  ```
  { spent, current: { kind, stage, care } | null, room: [{ kind }] }
  ```
- 진도 저장과 같은 방식으로 다룬다.
  - 저장 공간을 쓸 수 없거나 값이 깨졌으면 기본값으로 시작하고, 예외는 던지지 않는다.
- 부모 메뉴의 **진도 초기화**는 친구 키우기 기록도 함께 지운다 (⭐가 0이 되므로 맞춰야 한다).

## 7. 기타
- **테스트 모드** (`npm run dev:test`): 돌봐 주기에 ⭐가 들지 않는다.
- **음성**: 미리보기의 대사를 그대로 쓴다. 기존 `say()`를 쓰고 볼륨을 따른다.
  - AI 음성 파일 작업을 할 때 문장 목록에 포함한다.
- **그림 코드**: 미리보기의 그리는 함수를 `src/pets/art.ts`로 옮기고, 애니메이션 CSS를 함께 옮긴다.
  - `pet-preview.html`은 기능이 완성되면 지운다.
