# 시작할 때 전체화면 + 홈 화면에 추가 버튼 — 설계 (작은 변경)

## 왜
부모: 모바일 웹(안드로이드 크롬)에서 쓰면 주소창 때문에 불편하다. 다른 앱처럼 시작할 때 전체화면, 홈 화면 추가는 버튼으로. kids-learning에도 똑같이.

## 목표
- 브라우저에서 아이가 **처음 누르는 순간** 전체화면 (브라우저가 누르기 전엔 막음). 풀려도 다음 누름에 다시. 부모 메뉴에서는 다시 켜지 않음.
- APK(Capacitor), 홈 화면 앱(standalone/fullscreen), 마우스 기기(PC), 지원 안 하는 브라우저(아이폰 사파리)에서는 아무것도 안 함.
- 부모 메뉴에 "📲 홈 화면에 추가" 버튼. 크롬이 설치를 허락할 때(beforeinstallprompt)만 보임. 누르면 크롬 설치 창.
- 매니페스트 display를 `fullscreen`으로 (설치 앱의 상태 표시줄까지 숨김).

## 하지 않는 것
아이폰 대응, 전체화면 켜고 끄는 설정, APK 변경.

## 접근
- 고른 것: 첫 누름(pointerup, 터치에서도 사용자 동작으로 인정됨) 때 requestFullscreen — mutiny-sails `fullscreen.ts` 방식.
- 버린 것: 열리자마자 전체화면 — 브라우저가 막는다. 시작 버튼 새로 만들기 — 홈이 바로 뜨는 지금 흐름을 바꾼다.

## 빌더 몫
- `src/core/fullscreen.ts`(자동 전체화면), `src/core/install.ts`(설치 창 보관) — 두 앱에 같은 파일.
