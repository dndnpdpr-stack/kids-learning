# AI 음성 파일 설계 (짧은 설계)

작성일: 2026-11-19

## 목적
- 기기 내장 음성(TTS)이 딱딱하다는 피드백을 받았다.
- 그래서 AI로 만든 자연스러운 음성 파일을 앱에 넣는다.
- 같이 해결되는 문제:
  - Android 앱(WebView)에서 내장 음성이 나오지 않는 문제
  - 모바일에서 소리 크기 조절이 무시되는 문제

## 결정 사항 (사용자 선택)
- 음성 출처: AI로 미리 생성한 파일
- 서비스: Google Cloud Text-to-Speech

## 검토한 방법
| 방법 | 장단점 | 결과 |
|---|---|---|
| AI 음성 파일 미리 생성 | 모든 기기에서 같은 품질, 오프라인 가능, 소리 크기 조절 가능 / 생성할 때 API 키 필요 | ✅ 선택 |
| 부모 목소리 녹음 | 아이에게 친근함 / 300개 녹음 부담, 배포 시 개인 목소리가 들어감 | 제외 |
| 내장 TTS 개선만 | 비용 없음 / 기기마다 품질 다르고 Android 앱에서 소리가 안 남 | 보조 수단으로 유지 |

## 설계
- **문장 목록 (`src/voice/phrases.ts`)**
  - 콘텐츠 데이터에서 앱이 말할 수 있는 모든 문장을 `{text, lang}` 목록으로 만든다.
  - 포함 대상: 글자 이름, "이름, 단어!", "○을/를 찾아봐!", 조합 음절, 숫자, 안내 문장 등.
  - 각 화면이 실제로 말하는 문장이 모두 이 목록에 들어 있는지 확인하는 테스트를 둔다.
- **생성 스크립트 (`npm run gen:voice`)**
  - 환경 변수 `GOOGLE_TTS_API_KEY`로 Google TTS REST API를 호출한다.
  - 결과를 `public/voice/<해시>.mp3`와 `public/voice/manifest.json`으로 저장한다.
  - 이미 만든 파일은 건너뛴다. 그래서 문장을 추가했을 때 새 문장만 생성된다.
  - 키는 코드와 git에 저장하지 않는다.
- **음성 선택**
  - 한국어: `ko-KR-Neural2-A` (밝은 여성 목소리)
  - 영어: `en-US-Neural2-F`
  - 말하는 속도는 0.9로 한다.
  - 음성 이름은 스크립트 옵션으로 바꿀 수 있다. 사용자가 들어 보고 바꿀 수 있게 하기 위해서다.
- **앱 연결**
  - 앱 시작 시 manifest를 읽는다.
  - `setClipResolver`로 문장에 맞는 파일 경로를 돌려준다.
  - 파일이 없는 문장은 기존처럼 내장 TTS로 대체한다.
- **오프라인**
  - PWA 사전 캐시 대상에 mp3를 추가한다. 예상 크기는 약 3~5MB다.
  - check-precache 스크립트가 mp3도 검사하게 한다.
- **안전장치**
  - 최종 검토에서 미뤄 둔 항목인 "녹음 파일 재생에 안전 타이머가 없음"을 함께 해결한다.

## 비목표
- 앱 실행 중 실시간 AI 음성 호출 (앱은 계속 네트워크를 쓰지 않는다)
- 부모 메뉴에서 목소리를 고르는 기능
