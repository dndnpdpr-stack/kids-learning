# 놀이 학교

4~5세 아이가 **한글 · 숫자 · ABC**를 놀이처럼 배우는 게임입니다. 휴대폰 앱(Android)으로도, 일반 브라우저에서도 돌아갑니다. 인터넷이 없어도 됩니다.

처음 켜면 아이 이름을 묻고, 첫 화면 제목이 "○○의 놀이 학교"가 됩니다.

## 무엇을 하나

| 세계 | 배우는 것 | 놀이 |
|---|---|---|
| 🐰 숫자 | 1~5 세기 → 1~10 → 크기 비교 → 하나 더/덜 → 순서 → 더하기 → 20까지 | 숫자 만나기·따라 쓰기, 몇 개인지 세기, 더 많은 쪽 고르기 |
| 🐻 한글 | 자음 → 모음 → 가나다…하 | 그림 낱말로 만나기, 소리 듣고 찾기, 자음·모음 따라 쓰기 |
| 🦊 ABC | A~Z (5~4개씩 6묶음) | 만나기, 찾기, 따라 쓰기 |

- 묶음마다 3문제를 맞히면 다음 묶음이 열립니다.
- 맞힐 때마다 별 ⭐을 하나 받습니다.

### 친구 돌봐주기 🥚
- 강아지 · 고양이 · 병아리 · 나무 중 하나를 골라 키웁니다.
- 밥 · 목욕 · 놀기는 별 1개가 듭니다. 쓰다듬기 · 잠자기는 별이 들지 않습니다.
- 돌봐줄수록 친구가 4단계로 자랍니다. 다 자라면 친구 방(🧸)으로 이사 가고, 새 친구를 데려올 수 있습니다.
- **별이 없으면 퀴즈:** 아이가 이미 배운 것에서 한 문제가 나옵니다. 맞히면 별 없이 바로 돌봐줄 수 있고, 친구 성장에도 쳐줍니다.

### 부모 메뉴
- 첫 화면의 🔒를 3초 동안 누르고 있으면 열립니다. 아이가 실수로 들어가지 않게 하려는 것입니다.
- 볼륨, 아이 이름 바꾸기, 모은 별 보기, 기록 초기화를 할 수 있습니다.

## 실행하기

Node.js 22 이상이 필요합니다.

```bash
npm install
npm run dev        # 브라우저에서 보기 (http://localhost:5173)
npm run dev:test   # 테스트 모드: 모든 묶음 열림, 부모 메뉴 한 번 눌러 열기, 돌봐주기 별 안 듦
npm test           # 테스트 실행
npm run build      # 배포용 웹 빌드 (dist/, 오프라인 PWA)
```

## Android 앱(APK) 만들기

`android/` 폴더는 저장소에 올리지 않습니다. 처음 한 번은 직접 만들어야 합니다.

준비물:
- Android Studio (Android SDK)
- JDK 21. Gradle 8.14가 Java 25에서는 돌지 않습니다.

```bash
npx cap add android   # 처음 한 번만
npm run apk           # 웹 빌드 → 동기화 → 디버그 APK 빌드
```

- 결과물은 `android/app/build/outputs/apk/debug/app-debug.apk`에 생깁니다.
- 휴대폰으로 옮겨 설치하면 됩니다. 다시 설치하면 업데이트로 깔리고, 기록은 유지됩니다.
- JDK는 `ANDROID_STUDIO_JBR` 또는 `JDK21_HOME` 환경 변수로 지정할 수 있습니다. 자세한 건 `scripts/build-apk.mjs`를 보세요.
- 앱에서는 WebView 음성이 나오지 않아서, 휴대폰 음성 엔진(TTS)으로 말합니다.

## 기술

- Vite + TypeScript. 프레임워크 없이 DOM을 직접 다룹니다.
- 테스트: Vitest (jsdom).
- 오프라인 웹앱: vite-plugin-pwa.
- 앱 포장: Capacitor (Android. iOS는 Mac이 있어야 해서 아직 하지 않았습니다).
- 기록은 기기 안(localStorage)에만 저장합니다. 서버로 보내는 데이터는 없습니다.

## 폴더

```
src/
  content/   한글·숫자·ABC 학습 내용
  core/      문제 만들기, 진도 저장, 음성, 획 데이터
  pets/      친구 키우기 상태, 그림(SVG), 별이 없을 때 퀴즈
  ui/        화면들 (첫 화면, 세계, 만나기, 찾기, 따라 쓰기, 친구, 부모 메뉴)
tests/       화면·로직 테스트
docs/superpowers/specs/   기능별 설계 문서
scripts/     APK 빌드, 아이콘 생성 등
```
